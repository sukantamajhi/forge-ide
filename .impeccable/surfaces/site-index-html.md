# Forge landing page (site/)

Scope: Persuade. Landing page for Forge. Visitor: a developer deciding whether to try an early Windows editor. Three equal actions: download the installer, read/star the source, join the early-access list.

## Direction contract

THESIS: A page set like a hot-metal composing room: every headline is a cast slug of type metal, and the editor is the proof pulled from it. Refuses the dark-editor-screenshot hero with a neon glow and a row of feature cards.

OWN-WORLD: Vermilion pot-glow (#F25C2A family, taken from the logo's ember) drenches the first screen; type-metal slate and press-black carry the middle; cold proof-white holds the specimen sheet. Slabs of black "slugs" with raised type, ruled proof margins, registration ticks and galley numerals. Wood-type slab display (Bevan), a plain grotesk for reading, a mono only for code and shortcuts.

STORY: Forge is a native Rust editor you can already use. Visitors learn it keeps VS Code habits and Open VSX extensions, see what exists and what does not, and take one of three doors.

FIRST VIEWPORT: Vermilion field. Masthead with logo and links. The hook is set as three black slugs of different lengths ("An editor", "cast in", "Rust.") with raised type that casts in once on load. Beneath: one sentence, the three doors in a row (Download for Windows primary, Star on GitHub, Join early access), then a pinned proof: an HTML illustration of the Forge window bleeding off the bottom edge.
